# Archive

Code parked here is not actively maintained or run in CI (`pytest.ini` scopes test discovery to
`tests/`, excluding `archive/tests/`).

## Contents

- `src/blech_data_transfer.py`, `src/dataset_handler.py`, `tests/test_blech_data_transfer.py`,
  `tests/test_dataset_handler.py` — the original Katz Lab tool for manually copying a local
  recording to a shared server, gated on a metadata file being present, plus its recording-log
  handler. Archived because Hamilos Lab data doesn't arrive this way (it lands directly on the
  network share, generated by rigs, not manually copied per-researcher by a person selecting a
  destination folder). May be revived later, but reviving the per-user attribution step depends on
  first closing the "who recorded this session" metadata gap — see
  [hamilos_data_sentry#1](https://github.com/HamilosLab/hamilos_data_sentry/issues/1) (also filed as
  [Video_Lick_Monitoring#47](https://github.com/HamilosLab/Video_Lick_Monitoring/issues/47)).
- `server_only_files/users_list.txt` — the Katz Lab personnel roster the transfer tool used for
  its user-selection step. No Hamilos Lab equivalent exists yet (session provenance currently
  isn't recorded anywhere).
- `dataset_frame.csv` — a stale sample/live recording log from the archived transfer tool.
- `utils/mount_katz_drive.sh` — a CIFS mount script for the old Katz/Brandeis server. Mounting the
  Hamilos Lab network share is outside this repo's job (the sentry assumes the share is already
  mounted); archived rather than rebranded to keep the repo scoped to scanning/inventory.
